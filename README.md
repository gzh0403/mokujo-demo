# MOKUJO 木序｜理发店数字经营系统 V1.0 演示样品

这是一套可在浏览器中点击体验的演示样品，用于向理发店老板展示预约、到店服务、结算核销、会员次卡和推荐来源等经营闭环。

**演示样品 · 虚拟数据 · 非真实经营数据。** 页面中的金额均标有「模拟」，不能作为真实经营系统使用，也不是微信小程序正式产品。

## 在线体验

打开本仓库的 GitHub Pages 页面即可，不必登录 GitHub，也不必安装开发环境。

顶部工具条可在「顾客阿青 / 店员小林 / 老板木序」之间切换，三端共用同一套浏览器本地数据。可用「初始化数据」或「重置数据」按当天重新生成演示数据。

## 本地打开

下载本仓库后，直接打开 `index.html` 即可，不必联网。
